# DSA – Data Structures and Algorithms (Java)

This repository contains my practice programs for **Data Structures and Algorithms (DSA)** implemented in **Java**.
It focuses on improving logic building and problem-solving skills through basic to intermediate level problems.

---

## 📌 About This Repository

- **Language:** Java  
- **Purpose:** DSA practice  
- **Level:** Beginner to Intermediate  

This repository includes Java programs for common problems such as:
- Fibonacci series
- Factorial calculation
- Integer to binary conversion
- Swapping numbers
- Simple interest calculation
- Other basic programming problems

## ▶️ How to Run the Code

1. Clone the repository:
   ```bash
   git clone https://github.com/aniketbirdawade/DSA.git
   ```

2. Navigate to the project directory:
   ```bash
   cd DSA
   ```

3. Compile a Java file:
   ```bash
   javac FileName.java
   ```

4. Run the program:
   ```bash
   java FileName
   ```
